# EduHub

EduHub 프로젝트 저장소입니다.

## 폴더 구조

```
eduhub/
├── docs/          # 문서
├── .env.example   # 환경 변수 예시 (복사해서 .env로 사용)
├── .gitignore
└── README.md
```

## 시작하기

1. 저장소를 내려받습니다.
2. `.env.example`을 복사해 `.env`를 만들고 값을 채웁니다.

   ```bash
   cp .env.example .env
   ```

> `.env`에는 비밀 값이 들어가므로 Git에 올리지 않습니다 (`.gitignore`에 포함).
